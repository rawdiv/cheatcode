Editorial Solution

The "Two Sum" problem asks us to find indices of two numbers in an array that add up to a target value.

Approach 1: Brute Force

Check every pair of elements to see if they sum to the target. 

# Time: O(n²)
# Space: O(1)

def twoSum(nums, target):
    n = len(nums)
    for i in range(n):
        for j in range(i+1, n):
            if nums[i] + nums[j] == target:
                return [i, j]

Approach 2: Hash Map (Optimal)

Use a hash map to check for complements as we iterate through the array. 

# Time: O(n)
# Space: O(n)

def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
